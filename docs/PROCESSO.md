# Processo de Desenvolvimento

# Metodologia escolhida

Para organizar o desenvolvimento do ESM Forum foi escolhido o Kanban.

O Kanban possibilita a visualização das atividades do projeto e o acompanhamento do andamento de cada funcionalidade de forma simples.

# Organização

As tarefas foram organizadas em um GitHub Project utilizando as seguintes colunas:

- Todo
- In Progress
- Done

# Funcionalidades planejadas

As principais funcionalidades consideradas para evolução do sistema são:

- Sistema de votação
- Busca de perguntas
- Categorização por tags
- Perfil de usuário
- Notificação de novas respostas

# Utilização do quadro

No começo, todas as funcionalidades foram adicionadas a coluna Todo.

Quando o desenvolvimento de uma funcionalidade for iniciado, ela poderá ser movida para In Progress. Após sua conclusão, poderá ser movida para Done.

# Justificativa

O Kanban foi escolhido por permitir uma organização visual e simples das tarefas do projeto.

A utilização do GitHub Projects facilita o acompanhamento do desenvolvimento, permitindo visualizar rapidamente quais funcionalidades ainda precisam ser desenvolvidas, quais estão em desenvolvimento e quais já foram concluídas.

Esse processo também facilita a organização das próximas etapas do projeto e o acompanhamento da evolução do ESM Forum.
