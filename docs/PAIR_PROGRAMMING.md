# Pair Programming

# Conceito

Pair Programming é uma prática de desenvolvimento em que duas pessoas trabalham juntas na implementação de uma mesma tarefa.

Normalmente, uma pessoa assume o papel de Driver e outra o papel de Navigator.

# Driver

O Driver é responsável por escrever o código e executar as alterações no projeto.

Suas principais responsabilidades são:

- Implementar o código;
- Executar comandos;
- Realizar testes;
- Corrigir erros encontrados.

# Navigator

O Navigator acompanha o desenvolvimento e analisa o trabalho realizado pelo Driver.

Suas principais responsabilidades são:

- Revisar o código;
- Identificar possíveis erros;
- Sugerir melhorias;
- Verificar se a implementação atende aos requisitos.

# Aplicação no projeto

Neste projeto, o desenvolvimento está sendo realizado individualmente. Por esse motivo, não foi possível executar uma sessão tradicional de Pair Programming com dois desenvolvedores.

Entretanto, a prática pode ser aplicada ao ESM Forum em uma situação de desenvolvimento em equipe.

Por exemplo, durante a implementação da funcionalidade de busca de perguntas, o Driver poderia desenvolver a rota, o serviço e os testes necessários, enquanto o Navigator acompanharia a implementação, verificando a organização do código e o atendimento aos requisitos.

Após determinado período, os participantes poderiam trocar de função.

# Benefícios

A utilização de Pair Programming pode proporcionar:

- Revisão contínua do código;
- Identificação antecipada de erros;
- Compartilhamento de conhecimento;
- Melhoria da qualidade do código;
- Discussão de diferentes soluções para um problema.

# Conclusão

Mesmo não sendo aplicada diretamente nesta etapa individual do projeto, a prática de Pair Programming pode contribuir para a qualidade do ESM Forum em um ambiente de desenvolvimento colaborativo, principalmente durante a implementação e revisão de novas funcionalidades.
